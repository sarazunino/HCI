# HUMAN-COMPUTER INTERACTION 2025-2026
Autore: Sara Zunino
## 📝 Descrizione
Il progetto tratta l'analisi di grandi quantità di dati relativi all'industria degli anime, utilizzando Python come linguaggio di programmazione e Jupyter Notebook per l'elaborazione dei task e la visualizzazione dei grafici.

## 🚀 Come eseguire il progetto
I comandi sotto elencati devono essere digitati nel Terminale del tuo computer, assicurandoti di essere all'interno della cartella principale del progetto.
Per caricare automaticamente le librerie utilizzate possiamo seguire due metodi:
**Tramite requirements.txt** (due scelte)
A. `pip install -r requirements.txt`
B. Per mantenere il sistema pulito ed evitare conflitti tra librerie, si può creare un ambiente isolato:
    Crea ambiente: `python -m venv venv`
    Attiva: Windows:`venv\Scripts\activate`  Mac/Linux:`source venv/bin/activate`
    Installa: `pip install -r requirements.txt`

**Tramite conda**:
Se utilizzi Anaconda o Miniconda, puoi rigenerare l'ambiente esatto tramite il file YAML:
`conda env create -f environment.yml`
`conda activate hci_project`

Il Jupyter Notebook sarà così pronto per essere eseguito e caricherà automaticamente tutti le librerie e moduli necessari.
